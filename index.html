ACCESS

厳美へ行く

🚗 CAR / 車

  • 東北自動車道 一関IC → 国道342号 経由 約5km・8分(厳美渓まで)
  • 仙台方面からは東北道で一関ICへ
  • 盛岡方面からも東北道で一関ICへ
  • 須川方面は一関ICから国道342号経由 約46km・80分
  • 駐車場: 厳美渓周辺に市営無料駐車場・有料駐車場あり

🚌 TRAIN + BUS / 電車・バス

  • JR一ノ関駅 → 岩手県交通バス「厳美渓線」 約20分 → 徒歩1分
  • 須川方面: JR一関駅 → 岩手県交通バス「須川温泉線」 → 徒歩5分

🚄 SENDAI / 仙台から

  • 仙台駅からJRまたは高速バスで一ノ関駅・一関駅へ
  • 一ノ関駅からは上記バス「厳美渓線」等に乗り継ぎ

🚕 TAXI / タクシー

  • JR一ノ関駅等からの利用が可能です
  • 料金は変動するため、乗車前にご確認ください(未確認情報のため掲載していません)

🚴 BICYCLE / サイクリング

  • 国道342号は交通量・道路状況の変化があるため、走行時は十分注意してください
  • 距離・高低差・休憩場所等の詳細情報は準備中です(data pending)

ABOUT

GENBIについて

GENBIは、岩手県一関市厳美町の厳美渓を起点に、国道342号を通って須川温泉・須川岳方面までを案内する、個人運営・非営利の観光メディアです。広告や支援金は受け取っていません。

詳しくはABOUTページをご覧ください。
